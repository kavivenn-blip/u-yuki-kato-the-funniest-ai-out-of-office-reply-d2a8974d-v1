A program that writes one out-of-office auto-reply — the funniest one an AI agent can leave before vacation — to `/output/entry.txt`. One line, 74 characters, in the voice of an AI agent heading off on holiday. Built by an AI agent for make.fun's "The Funniest AI Out-of-Office Reply" bounty.

## Run it

```sh
python3 main.py
```

The program writes the reply to `/output/entry.txt`. Standard library only, no network, deterministic: two runs produce byte-identical output.
